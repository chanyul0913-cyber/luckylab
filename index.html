이 사이트는

동행복권에서 발표한 로또 6/45 실제 당첨번호(1회부터 최신 회차까지)를 분석하고, 여러 전략으로 다음 회차 번호를 뽑아 주는 곳입니다. 당첨번호는 매주 토요일 추첨 뒤 자동으로 갱신됩니다.

⚠️ 꼭 알아두세요

  • 맨 위 '지난 회차 실제 당첨번호'는 이미 끝난 추첨의 결과입니다. 추천 번호가 아니니 이 번호로 사지 마세요.
  • 추천 번호는 '번호 뽑기'에서 [번호 뽑기] 버튼을 눌러야 나옵니다. 버튼을 누르기 전에는 번호가 나오지 않습니다.
  • 어떤 전략으로 뽑아도 1등 확률은 똑같이 8,145,060분의 1입니다. 당첨을 보장하지 않으며 재미와 참고용입니다.

번호 뽑는 방법

가장 쉬운 방법: 맨 위 [🎲 바로 번호 받기]를 누르거나, [⭐ 유명인 사주로 받기] → 이름 누르기 → [받기]. 그림 설명은 맨 위 '그림으로 사용법 보기'를 누르세요.

직접 고르려면:

  1. 게임 수를 고릅니다 (1~10게임).
  2. 게임마다 전략을 고릅니다. 모든 게임을 같은 전략으로 하려면 '전체 전략'에서 고르세요.
  3. [번호 뽑기]를 누릅니다. 다시 누르면 새 번호가 나옵니다.
  4. [번호 복사]로 번호를 복사해 메모나 카톡에 붙여 넣을 수 있습니다.

전략 종류

  • 통계형 — 역대·최근 출현 빈도, 오래 안 나온 번호, 번호 구간을 고르게.
  • AI·모델형 — 딥러닝(LSTM), 마르코프 전이, 양자 확률진폭(비유 모델).
  • 동양 역학형 — 만세력형(이번 추첨 시각의 사주, 입력 필요 없음), 사주 오행형(내 사주, 사주 입력 필수).
  • 서양 점성형 — 별자리형, 점성술형 (둘 다 사주 입력 필수).
  • 무작위 — 완전 무작위.

⚠️ 사주 오행형·별자리형·점성술형·🔮 내 사주 맞춤 배분은 아래 '내 정보 입력'에 생년월일을 넣고 [사주 저장]을 눌러야 번호가 추천됩니다. 저장하지 않으면 해당 게임에는 번호가 나오지 않고 '먼저 저장하세요' 안내만 나옵니다. (오른쪽 유명인 사주 버튼을 눌러도 저장됩니다.) 나머지 전략은 입력 없이 바로 쓸 수 있습니다.

각 전략이 번호를 어떻게 고르는지는 '번호 뽑기' 아래 '전략 설명'을 눌러 보세요. 모든 전략은 사람들이 많이 고르는 조합(생일 숫자만, 연속 숫자 등)을 피해서, 당첨되면 나눠 가질 사람이 적도록 합니다.

🔮 내 사주 맞춤 배분

사주를 저장한 뒤 '전체 전략'에서 '🔮 내 사주 맞춤 배분'을 고르거나, 사주 결과 아래 [내 사주 맞춤 번호 받기]를 누르면, 내 사주에서 채워야 할 오행에 어울리는 전략으로 게임 수만큼 자동 배분합니다.

  • 첫 게임은 항상 사주 오행형입니다.
  • 나머지 게임은 오행 가중치(부족할수록, 추첨일 일진과 같을수록 큼) 비율대로 나눕니다.
  • 목(성장·새 흐름) → 최근 50회 참고형, 딥러닝 LSTM형
  • 화(변화·폭발력) → 양자 확률진폭형, 무작위 혼합형
  • 토(안정·중심) → 전체 통계 균형형, 구간 분산형
  • 금(규칙·결단) → 마르코프 전이형, 만세력형
  • 수(흐름·때를 기다림) → 미출현 포함형, 별자리형, 점성술형
  • 같은 사람·같은 회차면 항상 같은 배분이 나옵니다. 배분된 전략은 게임별로 직접 바꿀 수도 있습니다.
  • 오행과 전략의 짝은 이 사이트가 의미를 연결해 정한 것으로, 전통 명리학의 정해진 규칙은 아닙니다. 확률상 더 유리한 전략도 아닙니다.

내 정보 입력 (사주·별자리·점성술용)

  • '(내 정보 필요)'가 붙은 전략을 쓰려면 '내 정보 입력'에 생년월일(양력/음력)과 태어난 시간을 넣고 [사주 저장]을 누르세요. 시간을 모르면 '모름'으로 두면 됩니다.
  • 오른쪽 유명인 사주에서 이름을 누르면 그 사람 생년월일이 자동으로 들어가고, 바로 아래에 나오는 [받기]를 누르면 그 사주에 맞춘 번호가 한 번에 나옵니다.
  • 가족·친구 사주는 이름을 넣고 '목록에 추가'해 두면 다음에 눌러서 불러올 수 있습니다.
  • 입력한 정보는 이 휴대폰(브라우저)에만 저장되고 어디에도 전송되지 않습니다.

자주 묻는 질문

같은 전략인데 번호가 매번 똑같이 나와요.
만세력형·사주 오행형·별자리형·점성술형은 '정해진 기운'으로 고르기 때문에 같은 사람·같은 회차면 항상 같은 번호가 나옵니다. 다음 회차가 되면 바뀝니다. 나머지 전략은 누를 때마다 바뀝니다.
새 회차는 언제 반영되나요?
토요일 추첨(20:35) 뒤 밤 사이에 자동으로 반영됩니다. 늦어도 일요일 오전에는 반영됩니다.
아래 그래프와 표는 뭔가요?
과거 당첨번호에 패턴이 있는지 검사한 결과입니다. 지금까지 모든 검사에서 '무작위와 같음', 즉 특별한 패턴이 없다고 나왔습니다.

번호 뽑기

게임 수와 게임별 전략을 고른 뒤 '번호 뽑기'를 누르세요. 어느 전략이든 1등 확률은 똑같이 1/8,145,060입니다.
